서버 로그를 보다가 "시간당 요청 실패 횟수가 갑자기 늘면 어떻게 이상 탐지를 할까"를 생각해본 적이 있습니다. 이런 질문에 답하려면 결국 "이 값이 어떤 분포를 따른다고 가정할 것인가"부터 정해야 합니다. 분포를 잘못 고르면 그 위에 얹는 통계 검정이나 신뢰구간도 전부 의미가 없어지기 때문에, 실무에서 반복적으로 마주치는 세 가지 분포를 정리해봤습니다.

### 이항분포(Binomial): 정해진 횟수, 두 가지 결과

이항분포는 시행 횟수 n이 고정되어 있고, 각 시행이 성공/실패 두 가지 결과만 가지며, 성공 확률 p가 매 시행마다 동일할 때 성립합니다. "100개 중 불량품이 몇 개인가", "노출된 사용자 1,000명 중 몇 명이 클릭했는가" 같은 질문이 전형적인 이항분포 문제입니다.

A/B 테스트가 대표적인 활용처입니다. 두 버전(A, B) 각각에서 사용자가 전환했는지 여부는 성공/실패 이진 결과이고, 전체 방문자 수는 고정되어 있으니 전환 수는 이항분포를 따른다고 가정합니다. 이후에 다룰 가설검정(A/B 테스트 유의성 검정)의 출발점이 바로 이 가정입니다.

### 포아송분포(Poisson): 정해진 구간 안에서 몇 번 일어나는가

포아송분포는 이항분포와 달리 "전체 시행 횟수"라는 개념이 없습니다. 대신 일정한 시간이나 공간 구간 안에서 사건이 몇 번 발생하는지를 다룹니다. 사건들이 서로 독립적이고, 평균 발생률(λ)이 일정하며, 개별 사건이 드물게 일어난다는 전제가 깔려 있습니다.

시간당 서버 에러 발생 횟수, 콜센터에 걸려오는 시간당 문의 수, 특정 페이지의 하루 방문자 수 같은 카운트 데이터가 여기 해당합니다. 흥미로운 점은 이항분포에서 시행 횟수 n이 아주 크고 성공 확률 p가 아주 작을 때(np는 일정하게 유지), 이항분포가 포아송분포로 근사된다는 것입니다. "1,000만 번의 요청 중 각각이 실패할 확률은 0.001%"라는 이항분포 문제를, "시간당 평균 100번의 실패가 발생한다"는 포아송분포로 바꿔서 계산하면 훨씬 다루기 쉬워지는 이유가 여기 있습니다.

### 정규분포(Normal): 왜 항상 기본값처럼 취급될까

정규분포는 연속형 값이 평균을 중심으로 좌우 대칭인 종 모양을 이루는 분포입니다. 그런데 실제 데이터가 정규분포를 따르는지 확인도 안 하고 정규분포를 가정하는 경우가 너무 많다고 느낄 수 있는데, 여기엔 중심극한정리(Central Limit Theorem)라는 근거가 있습니다.

중심극한정리는 "표본의 크기가 충분히 크면, 원래 모집단의 분포 형태와 무관하게 표본 평균의 분포는 정규분포에 가까워진다"는 정리입니다. 원본 데이터가 이항분포든 포아송분포든 완전히 다른 모양이든 상관없이, 여러 번 반복 추출한 표본의 평균들을 모아보면 정규분포 모양이 나타납니다. 그래서 회귀분석의 잔차(residual) 정규성 가정, A/B 테스트에서 평균 전환율 차이에 대한 신뢰구간 계산, 모델 성능 지표를 여러 fold에 걸쳐 비교할 때 등, "평균"을 다루는 대부분의 통계 절차가 정규분포를 기본 가정으로 깔고 갑니다. 정규분포 자체가 데이터의 본질이라기보다는, 평균이라는 통계량의 표본분포가 정규분포로 수렴한다는 것이 핵심입니다.

### 코드로 세 분포 비교하기

```python
import numpy as np
from scipy import stats

# 이항분포: 전환율 5%, 방문자 1000명 중 전환 수
binomial_samples = stats.binom.rvs(n=1000, p=0.05, size=10000)

# 포아송분포: 시간당 평균 에러 5건
poisson_samples = stats.poisson.rvs(mu=5, size=10000)

# n이 크고 p가 작을 때 이항분포 ≈ 포아송분포
binomial_approx = stats.binom.rvs(n=100000, p=0.00005, size=10000)  # np=5
print("포아송 평균/분산:", poisson_samples.mean(), poisson_samples.var())
print("이항근사 평균/분산:", binomial_approx.mean(), binomial_approx.var())
# 두 분포 모두 평균 ≈ 분산 ≈ 5 에 가까워짐 (포아송분포의 특징: 평균 = 분산)

# 중심극한정리 확인: 포아송(비대칭)에서 표본평균을 반복 추출하면 정규분포에 수렴
sample_means = [stats.poisson.rvs(mu=5, size=30).mean() for _ in range(5000)]
print("표본평균의 분포 - 평균:", np.mean(sample_means), "표준편차:", np.std(sample_means))
```

포아송분포는 평균과 분산이 같다는 성질(λ)이 있어서, 실제 카운트 데이터의 분산이 평균보다 훨씬 크면(overdispersion) 포아송 가정이 깨진 것이고, 이럴 땐 음이항분포(negative binomial) 같은 대안을 고려하게 됩니다.

### 정리하면

셋 다 "몇 번 일어났는가"를 다루는 것 같지만 전제가 다릅니다. 이항분포는 시행 횟수가 고정된 성공/실패 문제, 포아송분포는 구간 안에서의 희귀 사건 카운트, 정규분포는 (원본 데이터가 무엇이든) 평균이라는 통계량이 수렴하는 지점입니다. 데이터를 보자마자 정규분포부터 가정하기 전에, "이게 애초에 몇 번의 시행 중 성공 횟수인지, 아니면 구간 내 발생 횟수인지"부터 구분하는 게 먼저인 것 같습니다.
